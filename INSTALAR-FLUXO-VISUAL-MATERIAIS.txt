MELHORIA: FLUXO VISUAL PARA VENDA DIRETA DE MATERIAIS

- "Adicionar item" sempre começa mostrando todos os produtos e serviços.
- A escolha de materiais aparece somente após selecionar o produto de venda direta.
- Os materiais aparecem em cartões com miniatura, nome, unidade e valor-base.
- Há busca de materiais e destaque visual do selecionado.
- Inclui a correção para salvar custo e preço de referência do material.

INSTALAÇÃO

1. Copie a pasta src deste pacote para a raiz do projeto e confirme a substituição.
2. Execute: npm run check
3. Execute: git add .
4. Execute: git commit -m "Melhora fluxo visual da venda direta de materiais"
5. Execute: git push origin main

Não existe nova migração do Supabase.
