### Regra de execução

Antes de começar o módulo N+1:
- validar módulo N;
- build verde;
- migration aplicada;
- teste responsivo;
- teste de isolamento quando aplicável;
- commit/tag de checkpoint.

Isso evita acumular erro oculto.
