# Entrada da Fase 1

Ao iniciar a Fase 1, criar uma pasta NOVA de projeto.

Não copiar `evoria-pro` como base executável.

## Primeira entrega da Fase 1

O ZIP da Fase 1 deverá conter um projeto que:

- instala com `npm install`;
- inicia com `npm run dev`;
- passa em `npm run lint`;
- passa em `npm run typecheck`;
- passa em `npm test` ou equivalente;
- passa em `npm run build`;
- possui manifest PWA;
- possui shell responsivo;
- possui Supabase client;
- possui migration foundation;
- possui RLS foundation;
- possui workflow GitHub Actions;
- possui `vercel.json`;
- possui README operacional;
- não possui Base44;
- não possui `.git`;
- não possui `node_modules`;
- não contém segredos.

## Decisões a fechar no início da Fase 1

1. nome público do aplicativo;
2. slug/repositório GitHub;
3. nome definitivo do schema Supabase;
4. identidade visual inicial;
5. projeto Supabase novo ou schema isolado em projeto existente.

Nenhuma dessas decisões deve exigir reescrever módulos.
